# Portfolio media placeholders

Add the final portfolio assets here using these names:

- `workspace.png` — authenticated document library and empty chat state
- `grounded-answer.png` — streamed answer with inline citations and source cards
- `document-chat-demo.gif` — sign in, upload, ask, inspect citation, and delete flow

Before capturing media, use a non-sensitive sample document and ensure no API keys, email addresses, access tokens, browser bookmarks, or private project identifiers are visible.
